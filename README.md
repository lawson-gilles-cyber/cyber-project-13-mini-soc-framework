# cyber-project-13-mini-soc-framework
Mini SOC framework combining log analysis, detection rules, and correlation


## Context

A Security Operations Center (SOC) integrates multiple capabilities to detect and respond to threats.

This project simulates a mini SOC framework combining multiple detection techniques.

---

## Objective

* Analyze logs
* Apply detection rules
* Correlate events
* Detect attack chains

---

## ⚙️ Features

* Log parsing
* Rule-based detection
* Event correlation
* Threat hunting logic
